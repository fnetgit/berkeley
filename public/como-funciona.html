Como o cálculo é feito

Esta página resume a lógica usada no simulador para calcular o clock lógico global, distribuir os ajustes e comparar a ordem dos envios antes e depois da sincronização.

Voltar ao simulador Retorne para preencher os nós e testar exemplos práticos.

Etapa 1

Escolha da referência

O simulador começa com o horário informado no servidor. Esse valor funciona como ponto de partida da rodada de sincronização.

Para cada cliente, o sistema compara o horário local com a referência observada. Quando existe hora de envio, ela também entra na leitura do cenário.

Etapa 2

Cálculo do drift

O algoritmo mede a diferença entre cada relógio e a referência do servidor. Essa diferença é o drift observado para cada nó.

drift = horário do nó - horário de referência

Depois disso, o simulador calcula a média dos drifts válidos para estimar o novo clock lógico global.

Etapa 3

Novo clock global

A média dos desvios é somada ao relógio do servidor. O resultado vira o horário comum que todos os clientes devem perseguir.

clock global = clock do servidor + média dos drifts

Etapa 4

Ajuste por cliente

Com o novo clock global definido, o simulador calcula quanto cada cliente deve adiantar ou atrasar.

ajuste = clock global - horário atual do cliente

Esse valor é o que aparece na tabela de ajustes.

Rankings

Ordem original e ordem após sincronização

A ordem original usa os horários de envio informados. Já a ordem após sincronização usa o horário de envio somado ao ajuste aplicado no respectivo cliente.

Quando um cliente não informa hora de envio, ele continua participando da sincronização, mas não contribui com um horário explícito para o ranking.

Leitura prática

Como interpretar o resultado

  • Se o ajuste for positivo, o cliente estava atrasado e precisa adiantar o relógio.
  • Se o ajuste for negativo, o cliente estava adiantado e precisa atrasar o relógio.
  • Se os rankings mudarem, isso indica que a sincronização alterou a ordem aparente dos eventos.
  • Quanto menores os ajustes, mais próximos os relógios já estavam entre si.
